# Выбор модели ИИ в Cursor

Актуализировано 3 сентября 2026 года по документации Cursor и разработчиков моделей.

Стоимость указана относительно, потому что она зависит от тарифа Cursor, режима Fast, объёма входных и выходных данных и использования кэша. Новая версия модели обычно предпочтительнее старой.

## Актуальные модели

| Модель | Расходы | Для чего подходит |
|:---|:---:|:---|
| **Claude Fable 5.1** | Очень высокие | Самые сложные автономные задачи, глубокое исследование и длительная работа агента. Это не модель для художественных текстов. Примерно вдвое дороже Opus 5. |
| **GPT-5.6 Sol** | Очень высокие | Флагман OpenAI для сложного анализа, архитектуры, программирования и длительных агентных задач. |
| **Claude Opus 5** | Высокие | Сложные рассуждения, архитектура, критичные документы, код и корпоративные задачи. Хороший выбор, когда цена ошибки высока. |
| **Gemini 3.1 Pro** | Высокие | Глубокий анализ сложных задач, исследований и мультимодальных материалов. В документации Google пока имеет статус Preview. |
| **GPT-5.6 Terra** | Средние | Основная рабочая модель OpenAI: хороший баланс качества и стоимости для анализа, документов и кода. |
| **Claude Sonnet 5** | Средние | Лучший баланс скорости и качества у Claude. Подходит для ежедневной аналитики, требований, документов и программирования. |
| **Kimi K3** | Средние | Длительные агентные задачи, большой контекст и работа с крупными документами или кодовой базой. |
| **Cursor Grok 4.6** | Средние | Совместная модель Cursor и SpaceXAI для сложного кода и интеллектуальной работы; хорошо использует инструменты Cursor. |
| **Cursor Grok 4.5** | Средние | Предыдущее поколение Grok. Для новых задач лучше Grok 4.6. |
| **GPT-5.3 Codex** | Средние | Специализированная модель OpenAI для программирования, изменения проектов и поиска ошибок. |
| **GPT-5.6 Luna** | Низкие | Самая быстрая и экономичная модель семейства GPT-5.6 для массовых и относительно простых задач. |
| **Gemini 3.8 Flash** | Низкие | Быстрая и недорогая модель для повседневной работы, кода, изображений, аудио, видео и больших документов. |
| **Composer 2.5** | Низкие* | Собственная модель Cursor для работы с файлами, терминалом и кодом.  Режим Fast стоит заметно дороже стандартного. |
| **Claude Haiku 4.5** | Низкие | Самая быстрая модель Claude: классификация, извлечение данных, краткие ответы и массовая обработка. |
| **GLM 5.2** | Низкие | Недорогая открытая модель Z.ai общего назначения. Подходит для обычных агентных и текстовых задач. |
| **Kimi K2.7 Code** | Низкие | Недорогая модель для кода. Cursor рекомендует для новых задач более сильную Kimi K3. |
| **GPT-5.4 Mini / GPT-5.4 Nano** | Низкие | Простые, массовые и хорошо формализованные задачи, где важнее стоимость, чем глубина анализа. |

\* Стандартный Composer 2.5 недорогой, но включённый по умолчанию вариант Fast тарифицируется выше.

## Старые модели

Claude Fable 5, Claude Opus 4.8/4.7/4.6/4.5, Claude Sonnet 4.6/4.5/4, GPT-5.5/5.4/5.2/5.1, Gemini 3.7/3.6/3.5/3 Flash и Gemini 2.5 Flash могут оставаться доступными или быть скрытыми в Cursor. Для новой работы обычно стоит выбирать актуальную модель того же семейства.

## Рекомендации для системного аналитика

### Лучший универсальный выбор — Claude Sonnet 5

Подходит для ежедневной работы:

- сбор и уточнение требований;
- описание процессов AS-IS и TO-BE;
- подготовка функциональных и нефункциональных требований;
- поиск противоречий и пропусков;
- проектирование API, интеграций и моделей данных;
- подготовка BPMN, UML, Use Case, User Story и критериев приёмки;
- разбор протоколов встреч и больших документов.

### Для самых сложных решений — Claude Opus 5 или GPT-5.6 Sol

Использовать, когда нужно:

- сравнить несколько вариантов архитектуры;
- найти неочевидные риски и конфликтующие требования;
- разобрать запутанный процесс с большим количеством исключений;
- проверить критичный документ перед согласованием;
- провести глубокий анализ системы целиком.

### Для хорошего баланса цены и качества — GPT-5.6 Terra

Подходит для требований, регламентов, анализа процессов, SQL, API и обычных архитектурных задач. Это разумная альтернатива Sonnet 5.

### Для схем, скриншотов, аудио и видео — Gemini 3.8 Flash

Полезна, если исходные данные содержат диаграммы, интерфейсы, записи встреч или видео процессов. Быстро обрабатывает большие объёмы и стоит дешевле флагманов. Для особенно сложных выводов можно перепроверить результат на Gemini 3.1 Pro, Opus 5 или Sol.

### Для очень больших материалов — Claude Sonnet 5, Gemini 3.8 Flash или Kimi K3

Подходят для анализа крупных регламентов, технической документации и кодовых баз. Fable 5.1 имеет смысл только для действительно сложной длительной автономной работы: для обычного анализа она избыточна и дорога.

### Для реализации прототипа в Cursor — Composer 2.5, Grok 4.6 или GPT-5.3 Codex

Эти модели удобны, когда после анализа нужно создать или изменить файлы проекта, написать SQL, код интеграции либо рабочий прототип.

## Важно

Модель помогает анализировать, но может уверенно допустить ошибку. Факты, расчёты, требования, BPMN/UML-схемы и архитектурные решения нужно проверять человеку.
